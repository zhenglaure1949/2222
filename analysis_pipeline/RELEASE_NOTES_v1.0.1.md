# IgA RIPS formal reanalysis v1.0.1

This is a metadata-only archival patch release created after enabling the GitHub–Zenodo integration.

Scientific analyses, derived results, figures, supplementary tables, and validation conclusions are unchanged from v1.0.0.

## Validated contents

- Formal pyUCell analysis of GSE127136 and GSE286911
- Patient-level GSE127136 pseudobulk analyses
- All-QC, Top-UMI, and five-seed GSE286911 sensitivity analyses
- Four-strategy GSE220100 NanoString normalization audit
- Runtime-verified RIPS gene provenance table
- Submission figures and checksummed reproducibility package
- Validation status: PASS

## Scientific boundary

The package supports a robustness-audit and hypothesis-generation interpretation. It does not establish a stable IgAN–IgAVN disease classifier or validated biomarker.
